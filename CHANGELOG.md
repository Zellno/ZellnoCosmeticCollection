# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-22

### Added

- Initial Zellno Cosmetic Collection package.
- `Zellno_WojtekTShirt` as the first cosmetic item.
- Original Wojtek commemorative artwork.
- Zellno emblem for the front of the T-shirt.
- Signed and audited DayZ PBO build.
- Reversible local testing installer.
- Licensing and provenance documentation.

### Changed

- Migrated the mod identity from Zellno Wojtek T-Shirt to Zellno Cosmetic Collection.
- Renamed the package to `ZellnoCosmeticCollection.pbo`.

### Compatibility

- Preserved the existing class name `Zellno_WojtekTShirt`.
- Preserved the inherited vanilla T-shirt gameplay attributes.
