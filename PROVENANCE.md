# Provenance

## Project identity

Project: `Zellno Cosmetic Collection`

Preserved first item class: `Zellno_WojtekTShirt`

The class name was preserved when the original development package was
migrated to Zellno Cosmetic Collection.

## Wojtek artwork

The Wojtek illustration was generated specifically for this project using
AI image-generation tooling under the creative direction of Zellno.

The composition was inspired by the historical Wojtek bear and includes an
original depiction of a bear carrying an artillery projectile.

No historical photograph, military badge or third-party illustration was
used as source artwork.

Historical reference:

https://eng.ipn.gov.pl/en/news/9982,On-15-November-1947-Wojtek-the-bear-was-moved-from-the-Anders-Army-to-the-Edinbu.html

The reference was used for factual and thematic inspiration only.

## Zellno emblem

The front emblem was generated specifically for this project using AI tooling.
Its creative reference was a Zellno Discord icon supplied by the project owner.
The result is a newly created version of the Zellno identity.

## Vanilla reference material

The clothing layout was studied using files from a legitimate local DayZ
installation and the official DayZ Tools.

Extracted vanilla PNG files and editable documents containing embedded vanilla
texture data are development references and are excluded from Git.
